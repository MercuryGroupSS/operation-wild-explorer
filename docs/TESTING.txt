OPERATION WILD EXPLORER 2.0.0 — TEST NOTES
========================================

Test scope: game code and layouts were exercised in an isolated Chromium
document at mobile and tablet viewport sizes. Because local browser
navigation was unavailable in this build environment, localStorage and
GPS were mocked in the interaction tests. The service worker was tested
in a Node VM with mock network/cache APIs, not an installed Safari PWA.
No claim is made that this package was tested on a physical iPhone.

On-device checks still needed after your upload:
- iPhone Safari/Home Screen installation and icon display.
- Real GPS permission, denied permission, and reported accuracy.
- Narration voice and optional audio on the device.
- Offline reload after the deployed app finishes caching.
- Existing real browser save availability on the same origin.
- Deployed Netlify security headers and service-worker update behaviour.
